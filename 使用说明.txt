================================================================
  赛尔号数据查询工具 - 使用说明
================================================================

【软件说明】
  本工具用于查询赛尔号个人精灵/道具数据及图鉴数据。
  双击 SeerDataQuery.exe 启动，在浏览器中进行查询。


【环境要求】
  1. Windows 10 / 11
  2. 已安装 MySQL（5.7 或 8.0），且服务处于运行状态
  3. 无需单独安装 Python（已内置在程序中）


【文件夹放置（重要）】
  请将本文件夹整体放到「雷小伊」的同级目录，例如：

    D:\61seer\
      ├── 雷小伊\
      │   └── data\              （图鉴 .db 文件）
      ├── 重聚\
      │   └── seer_cfg\user\     （用户存档 .ini 文件）
      └── SeerDataQuery_dist\    （本文件夹，名称可自定义）
            ├── SeerDataQuery.exe
            ├── config.json
            ├── 使用说明.txt
            ├── 使用说明.md
            └── _internal\       （请勿删除）

  注意：
  - 必须保留整个文件夹，不要只复制 .exe
  - 不要删除或移动 _internal 文件夹


【首次使用 - 配置数据库】
  1. 用记事本打开本文件夹中的 config.json
  2. 在 "password" 一栏填写你的 MySQL root 密码，例如：

       "password": "你的密码"

  3. 如 MySQL 用户名不是 root，请同时修改 "user"
  4. （可选）如有多个游戏账号，在 "account" -> "id" 填写你的账号数字；
     留空则自动读取最新日期的存档文件
  5. 保存文件后重新双击 SeerDataQuery.exe

  默认数据库名为 seerNew，一般无需修改。
  如 5000 端口被占用，可将 "server" -> "port" 改为 5001 等。


【启动步骤】
  1. 确认 MySQL 服务已启动
  2. 确认文件夹已放在「雷小伊」同级目录
  3. 确认 config.json 已填写 MySQL 密码
  4. 双击 SeerDataQuery.exe

  启动器会自动检测环境与路径：
  - 全部通过：自动打开浏览器，访问 http://127.0.0.1:5000
  - 检测失败：窗口会显示具体原因，按提示修正后重试

  关闭程序：在黑色命令行窗口按 Ctrl+C，或直接关闭窗口。


【网页功能】
  1. 测试连接 / 更新数据库
     - 页面顶部可测试 MySQL 连接
     - 「更新数据库」会依次导入图鉴、个人精灵/道具并生成查询表
     - 首次使用或游戏数据有更新时，建议先点一次「更新数据库」

  2. 数据查询（四步）
     - 选择数据分类（个人数据 / 图鉴数据）
     - 选择查询类型
     - 道具查询可选道具分类
     - 输入关键词后搜索，或留空点「查看全部」

  3. ID 搜索
     - 单个 ID：2400007
     - 多个 ID：1,3,5
     - 范围：150-200
     - 可组合：1,150-200


【常见问题】

  Q: 提示「项目路径不正确」？
  A: 将本文件夹移动到与「雷小伊」「重聚」同级的位置，参见上文目录示例。

  Q: 提示「MySQL 连接失败」？
  A: 检查 MySQL 是否启动；检查 config.json 中的密码、用户名是否正确。

  Q: 提示「请先填写 MySQL 密码」？
  A: 编辑 config.json，在 password 字段填入密码后保存，再重新启动。

  Q: 网页打不开或端口占用？
  A: 修改 config.json 中 server.port 为其他端口（如 5001），重启程序。

  Q: 更新数据库失败？
  A: 确认 雷小伊\data 下有 .db 文件；
     确认 重聚\seer_cfg\user 下有 账号-日期.ini 格式的存档文件。

  Q: 可以改文件夹名字吗？
  A: 可以，只要仍与「雷小伊」在同一级目录即可。


【文件说明】
  SeerDataQuery.exe   主程序，双击启动
  config.json         数据库与端口配置（需自行填写密码）
  config.example.json 配置模板（参考用）
  使用说明.txt        纯文本版说明
  使用说明.md         Markdown 版说明
  _internal\          程序运行所需文件，请勿删除
  data\               运行后自动生成的缓存目录，可忽略
